**Перелік підтримуваних запитів:**
Єдина точка входу: api.php.

Ресурс: `resource=tasks` (`id`, `title`, `due_date`,
`priority`, `done`).

- GET без `id` - це отримання списку завдань (`200`).
  Необов'язковий параметр `q` - пошук за пріоритетом.
- GET з `id` - отримання одного запису (`200`)
  або `404`, якщо запис не знайдено.
- POST без `action` - створення нового завдання (`201`).
  Обов'язкові поля: `title`, `priority`.
  Необов'язкове поле: `due_date`.
  При некоректних або відсутніх обов'язкових полях - `400`.
- POST з `action=complete` - позначити завдання
  виконаним (`done = 1`). Обов'язковий параметр `id`
  передається в тілі запиту.

### Приклади запитів

GET api.php?resource=tasks

GET api.php?resource=tasks&id=1

POST api.php?resource=tasks

POST api.php?resource=tasks&action=complete

### Приклад успішної відповіді
```
{
"success": true,
"data": {
"id": 1,
"title": "Підготувати звіт",
"due_date": "2026-11-30",
"priority": "Високий",
"done": 0}
}
```
### Приклад відповіді з помилкою
```
{
"success": false,
"error": "Завдання не знайдено"}
```
### Коди статусів HTTP

- 200 - успішне виконання запиту.
- 201 - завдання створено.
- 400 - некоректні параметри.
- 404 - ресурс, дія або завдання не знайдені.
- 405 - метод не підтримується.
- 500 - внутрішня помилка сервера.

Усі відповіді повертаються у форматі JSON
